# 본 컬럼·리액터·스케일 패널 수정

2026-09-22에 [Active Theory](https://activetheory.net/)의 실제 화면을 다시 확인했다. 본 컬럼 구간은 작은 스크롤을 반복하며 모니터의 앞면과 옆면, 입자 덩어리의 위치를 비교했다. 스케일 패널은 마우스를 움직이는 동안과 멈춘 뒤를 따로 캡처했다. 참조 화면은 1440 × 900이며, AT가 사용하는 내부 스크롤 값과 이 사이트의 진행률을 같은 값으로 취급하지 않았다.

스케일 패널은 기존 포인터 흐름 텍스처를 공유한다. 별도 영상이나 렌더 패스를 추가하지 않았다. 금속 마모 텍스처는 고정 시드로 만든 256 × 256 데이터이며 재질을 해제할 때 함께 해제한다. AT의 모델·로고·영상·텍스처를 결과물에 복사하지 않았다.

## 검증 조건

변경 전 기준은 `1c31913ce818b1e35c9bb7aa2f309fa862db5226`이다. 전후 캡처는 같은 1440 × 900 화면, DPR 1, 스크롤 위치, 프레임 시각을 사용하고 영상을 2초에 고정한다. 별도로 마우스 이동, 역방향 스크롤, 390px 너비 화면을 확인한다.

실제 셰이더를 단독으로 렌더한 픽셀 검사에서는 다음을 확인했다.

- 본 컬럼·리액터·스케일 패널 구간에서 포인터 리본과 흰 점 모두 0픽셀. 상단·하단 포레스트는 효과 유지. 사선 경계 검사는 안티앨리어싱 여유 폭 0.02 바깥을 비교하며 누출 0픽셀.
- 리액터 O를 정면에서 측정한 지름 비율은 가로 0.6702, 세로 0.6699. 점 하나의 크기와 픽셀 반올림 때문에 수학적 2/3과 작은 차이가 있음.
- 스케일 패널은 좌·우 포인터에 각각 가까운 영역이 반응. 포인터가 떠난 뒤에도 흐름 텍스처에 남은 변형을 확인했으며, 흐름이 감쇠한 뒤 기준 화면과의 차이는 0픽셀. CPU 인스턴스 행렬은 유지.
- 모니터의 회전·높이·깊이 변화와 역방향 복원, 앞쪽 모니터와 체인의 실제 광선 교차, 모니터 클릭·영상 재생 검사를 통과.

원본과 픽셀 단위로 일치한다는 판정은 하지 않았다. 자체 모델과 영상의 차이가 남으며, 작은 화면과 소프트웨어 렌더러는 조각 수와 재질 효과를 줄인다.
