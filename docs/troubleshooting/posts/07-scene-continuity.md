# 다음 장면을 막고 있던 천장을 걷어냈다

본 컬럼과 모니터를 지나 리액터로 내려가면 남색 면이 화면 아래를 덮었다. 파티클의 수렴 과정을 가리려고 넣은 큰 천장이 다음 장치까지 막고 있었다. 앞의 6편 이후, PR #18에서 이 전환과 모니터 배치를 다시 손봤다.

## 장치 덮개와 방 전체의 천장

![수정 전 본에서 리액터 전환](../../screenshots/continuity-v18/before/scroll-650.jpg)

*수정 전 실제 화면 · 스크롤 65%. 모니터 아래의 불투명 면이 리액터를 가린다.*

![수정 후 본에서 리액터 전환](../../screenshots/continuity-v18/after/scroll-650.jpg)

*수정 후 실제 화면 · 같은 스크롤과 뷰포트. 재질과 모니터 배치 변경도 포함된다.*

큰 천장 메시의 렌더링을 끄고 장치 자체의 작은 덮개는 남겼다. 천장의 좌표도 접점 검사에 계속 사용한다. 큰 면을 그리지 않으니 화면과 깊이 버퍼에서 다음 장치를 가리지 않는다.

본 컬럼은 전환 끝에서 위로 10만큼 밀려나고 있었다.

```ts
// 변경 전 이동량 중 전환 후반 항
const spineOffset = -12 * (1 - emergence)
  + 10 * smooth(.60, .67, progress)
```

두 번째 항을 제거했다. 본은 내려가는 기준점을 따라가며, 사선 경계가 지나간 부분부터 가려진다.

## 경계 양쪽에 필요한 입자 형태

기존 파티클은 스크롤에 따라 본 주변 흐름에서 리액터의 O 형태로 변했다. 이 형태를 화면 전체에 사용하니 경계 위의 본 주변 입자까지 먼저 수렴했다.

두 장면이 겹치는 동안 본 주변 형태의 Points를 하나 더 그렸다. 위치·속성 버퍼는 공유하고 위쪽에는 본 형태, 아래쪽에는 수렴 형태를 표시한다. 기본 위치는 스크롤 진행률로 계산해 정지 중에 흐르지 않는다.

버퍼를 다시 올리는 비용은 없지만 겹치는 동안 draw와 픽셀 처리량은 늘어난다. 복제 필드가 완전히 가려지면 숨기고, 왕복 측정으로 비용을 확인했다.

## 리액터와 스케일 사이의 공통 경계

리액터에서 스케일 패널로 내려갈 때는 카메라 높이로 상단 장치를 통째로 숨겼다. 화면에 리액터 일부가 남아 있어도 카메라가 바닥 아래로 내려가면 사라졌다.

`deviceExit`를 공통 화면 경계로 사용하고 각 영역을 다음처럼 나눴다.

| 영역 | 위 경계 | 아래 경계 |
| --- | --- | --- |
| 본·모니터 | 모니터 진입 | 리액터 진입 |
| 리액터·바닥·주변 설비 | 리액터 진입 | 스케일 진입 |
| 스케일·하부 천장·투영광 | 스케일 진입 | 마지막 포레스트 진입 |

물체의 위치는 3D 공간에 두고 경계를 화면 좌표로 계산한다. 하부 천장과 영상에서 가져온 빛은 별도 그룹으로 옮겨 상단 장치가 숨겨져도 남게 했다.

![수정 후 리액터와 스케일의 공유 경계](../../screenshots/continuity-v18/after/scroll-765.jpg)

*수정 후 실제 화면 · 스크롤 76.5%. 상단 설비와 하단 패널 사이의 사선 경계.*

## 본을 가로지르던 모니터

패널의 위치와 방향을 모두 `turn = step * 1.13`으로 계산했다. 스크롤할 때 모니터가 원형 경로를 돌아 본과 체인 사이를 통과했다. 유리 너머로 구조가 비쳐 교차가 더 잘 드러났다.

패널마다 방향과 앞뒤 깊이를 고정하고, 스크롤은 세로 위치에만 반영했다. 패널은 체인 앞에 배치했다. 호버하면 회전하는 대신 컬럼 바깥쪽으로 조금 이동한다.

본 세그먼트는 높이를 키우고 데스크톱 개수를 18개에서 13개로 줄였다. 간격만 벌렸을 때 생기던 빈틈을 줄이면서 각 본의 두께를 유지하려는 조정이었다.

![본 세그먼트와 고정 방향 모니터](../../screenshots/continuity-v18/after/scroll-500.jpg)

*수정 후 실제 화면 · 스크롤 50%. 본과 체인 앞에 배치한 모니터.*

스케일 재질은 타일별 거칠기, 박막 반사와 미세 표면 변화를 조정했다. 처음에 반사만 키웠을 때는 화면이 희게 뭉개져 강도를 다시 낮췄다. 넓은 굴곡으로 면 방향을 달리해 밝은 타일과 어두운 타일이 함께 보이게 했다.

![스케일 패널의 재질](../../screenshots/continuity-v18/after/scroll-850.jpg)

## 포레스트 경계 밖의 섬광

느린 섬광은 생성 위치와 이동 후 픽셀에서 포레스트 경계를 검사한다. 생성 위치만 제한하면 이동 중 다른 장면으로 넘어갈 수 있었다. 중간 장면으로 나오면 이전 궤적을 비워 빠르게 돌아갔을 때 남은 선이 나타나지 않게 했다. 다른 입자의 포인터 변형은 유지했다.

마지막 링의 리본은 스크롤 도중 아래에서 위로 뒤집혔다. 위쪽에 붙는 자세를 보이지 않는 중간 구간에서 미리 설정했다. 마지막 숲에 진입할 때는 이미 링 위에 붙어 있다.

[실행 기록](../../scene-continuity.md)에 공유 경계 밖의 픽셀, 정지·역스크롤 복원, 모니터 방향·호버와 왕복 측정을 남겼다. 재질은 화면을 비교하며 조정했으며 유사도를 수치로 측정하지는 않았다.
