# 포레스트 지면과 장면 재질·움직임 수정

2026-09-24에 [Active Theory](https://activetheory.net/)의 본 컬럼, 리액터 챔버, 스케일 패널을 스크롤·정지·포인터 입력으로 관찰했다. 사용자가 제공한 확대 이미지도 입자와 본 컬럼의 비교 기준으로 사용했다. 아래 내용은 화면 관찰과 Aether의 구현 선택을 구분한다. 참고 사이트의 코드·모델·텍스처·영상은 가져오지 않았다.

## 구현 경계

리액터의 움직임은 유체 시뮬레이션이 아니라 시간에 따라 변하는 절차적 흐름이다. 스크롤 역복원은 같은 시간·포인터 조건에서 비교한다. Pause motion과 reduced motion은 기존 장면 시간을 멈춰 이 흐름도 정지시킨다.

PC 수면은 기존 평면 반사 타깃 하나를 재사용한다. 모바일·software 프로필은 반사 타깃 없이 움직이는 법선과 개구부 조명으로 표현한다. 비눗방울은 투명 sprite이며 실제 화면 굴절이나 물리적 막 시뮬레이션은 사용하지 않는다. 따라서 원본과 픽셀 단위로 같은 결과를 보장하지 않는다.

## 검증 기준

- 실제 포레스트 vertex shader에서 wrapper 이동과 지형 투영을 분리해 확인한다. 카메라를 움직이면 투영이 바뀌고 되돌리면 복원되어야 한다.
- 실제 입자 vertex shader의 GPU 좌표로 꽃 입자의 하강·역복원, 리액터의 정지 중 이동·시간 고정·스크롤 역복원을 확인한다.
- 리액터 개구부, 받침, 바닥, 천장, 수면의 접점과 장면별 clipping·depth 차폐를 검사한다.
- 스케일 패널의 중앙·측면 파동, 포인터 반응, 정지·복원 및 모바일 네이티브 스크롤을 검사한다.
- 같은 viewport·스크롤·합성 프레임 시간·영상 시각으로 변경 전후를 캡처한다. GPU 드라이버에 따른 미세한 차이는 남을 수 있다.

## 검증 결과

lint, typecheck, build와 로컬 전체 검사 105개를 통과했다. 모바일 전용 검사 1개는 PC에서 제외했다. 최종 GPU 캡처에서 본 컬럼의 노이즈 함수와 경계 지역변수 이름 충돌을 발견해 수정했다. software 프로필에서도 고급 재질을 강제로 컴파일·렌더링하는 회귀 검사 1개를 추가해 통과했다. 최종 커밋의 전체 검사는 PR CI에서 다시 실행한다.

PC 1440×900, 모바일 390×844, DPR 1에서 전후 32장을 캡처했다. 합성 프레임 시간과 영상 시각 2초를 맞췄고 렌더링 오류는 없었다. [캡처 조건·해시·측정 기록](evidence/world-scene-validation.json)과 [전후 화면](screenshots/world-rebuild/)을 함께 보관한다.

RTX 2060 SUPER에서 각 버전별 하강·상승 19초를 한 번씩 측정했다. 변경 전 프레임 P95는 양방향 16.7ms, 변경 후는 하강 16.8ms·상승 16.7ms였다. 변경 후 하강에서 66.7ms 프레임 1개가 있었고 콘솔 오류는 없었다. 변경 후 GPU timer query 표본은 수집되지 않아 GPU 비용 비교는 할 수 없다. 단일 실행이며 기준 버전은 preview, 변경 버전은 dev 서버였으므로 성능 개선의 근거로 사용하지 않는다.
