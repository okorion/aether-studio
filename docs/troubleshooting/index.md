## 기록의 범위

1~6편은 PR #17 병합 `cfee1e1`, 7편은 PR #18의 구현·검사 기록을 다룬다. 코드 생성과 수정에는 AI를 사용했다. 글은 저장된 코드·리뷰·검증 자료를 바탕으로 썼다. 다른 프로젝트의 경험이나 확인되지 않은 작업은 추가하지 않았다.

현재 모니터는 7편의 고정 방향 배치에서 나선 회전으로 바뀌었다. 스케일 패널의 원형 파동과 중간 장면의 잔상 제거도 [PR #20 후속 기록](../scene-reference-detail.md)에 있다. 개발할 때는 [현재 구조](../architecture.md)를 함께 확인한다.

이번 개정은 문장과 설명 그림을 고친 버전이다. 실제 화면 캡처와 과거 측정값은 유지했다. PR #16 챔버 표본의 최대 draw 226처럼 특정 빌드에 속한 값은 당시 조건과 함께 읽어야 한다.

## 그림과 측정값의 구분

`docs/screenshots/`의 파일은 당시 실행 화면이다. `images/`에는 설명용 도식과 측정 기록을 다시 그린 차트가 있다. 캡션에는 뷰포트·스크롤과 영상 시각을 맞췄는지 적었다. GIF는 캡처를 묶은 자료로, 재생 간격을 앱의 FPS로 사용하지 않는다.

RAF 간격, JS 콜백 시간, WebGL GPU 쿼리는 측정 범위가 다르다. 서로 다른 빌드와 구간의 숫자는 각 실험 안에서 비교했다. 실제 Safari/iOS, 저사양 모바일과 장시간 발열·메모리 검사는 남아 있다.

## 파일 보관과 Velog 게시

[공개 저장소](https://github.com/okorion/aether-studio)에 Markdown과 이미지를 함께 보관한다. [릴리스](https://github.com/okorion/aether-studio/releases)에서는 이미지가 내장된 HTML과 Markdown·이미지를 묶은 ZIP을 받을 수 있다.

ZIP의 `velog/` 폴더는 게시용 원고다. 본문은 원본과 같고 이미지·근거 주소는 고정 커밋의 공개 링크다. 에디터에 붙여 넣은 뒤 표·코드·그림을 미리보기에서 확인하고 직접 게시하면 된다. 자세한 파일 구성은 [보관 안내](README.md), 문체 기준과 수정 내역은 [편집 기록](editorial/README.md)에 있다.
