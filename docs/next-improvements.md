# 후속 검증과 개선

최근 장면 배치와 입력 수정은 [PR #20 기록](scene-reference-detail.md), 검사 범위는 [검증 안내](testing.md)에서 확인한다. 현재 남은 작업은 실제 기기 확인, 장시간 실행, 장면 겹침 비용 측정이다.

| 순서 | 확인할 내용 | 완료 기준 |
| --- | --- | --- |
| 실제 Safari/iOS·저사양 기기 | 전체 스크롤 왕복, 첫 영상 재생, 가로·세로 전환, 백그라운드 복귀, 모션 축소와 실패 시 대체 화면 | 기기·OS·브라우저·DPR·선택 코덱을 기록하고 전환 누락·영상 복귀 실패·입력 막힘을 확인한다. 에뮬레이션 결과로 대신하지 않는다. |
| 장시간 실행 | 같은 경로를 10~15분 왕복하며 디코더·GPU 메모리·발열과 품질 변화를 관찰 | 시간대별 자원 수와 프레임 간격, 품질 단계별 화면을 남긴다. 일시적인 증가와 계속 누적되는 증가를 구분한다. |
| 겹침 비용과 근접 표면 | 모니터·본 컬럼·리액터·물 반사가 동시에 보이는 구간과 가까운 표면을 비교 | 같은 카메라·영상 위상·입력에서 GPU p95·최댓값을 반복 측정한다. 캡처를 줄인 경우 오래된 반사·팝인·가림 회귀가 없는지도 확인한다. |

첫 모니터 진입에서 남았던 긴 프레임은 [PR #15의 원인 분리](monitor-transition-performance.md) 후 해당 데스크톱 환경에서 재현되지 않았다. 이 결과를 미해결 오류로 계속 나열하지 않고, 다른 기기에서도 같은지 확인한다. 당시 최대 draw 수나 개선율을 현재 모델의 비용으로 옮겨 쓰지 않는다.
