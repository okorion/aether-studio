## 검수 절차

[`check-troubleshooting-editorial.py`](../../../scripts/check-troubleshooting-editorial.py)는 기준 버전과 비교해 코드 실행 부분·측정표·이미지 참조·이슈 ID를 검사한다. 긴 문장과 반복 도입은 검토 후보로만 출력한다. 이를 AI 작성 여부나 문체 점수로 해석하지 않는다.

도식 생성기는 모든 제목·문구·글자 영역을 [figure-text.json](figure-text.json)에 기록한다. 그림 생성 시 지정 영역을 벗어나면 파일 저장 전에 실패한다. 이후 실제 PNG와 본문 삽입 화면을 확인한다.

보관본 검수에서는 원고와 게시용 Markdown의 본문, 파일별 해시, 이미지, 오프라인 내부 링크, PC·모바일 레이아웃과 ZIP을 확인한다. 자동 검사 결과와 화면은 개정 릴리스의 QA 자료로 보관한다. 실제 Velog 에디터에서의 최종 미리보기는 사용자가 직접 게시할 때 확인한다.
